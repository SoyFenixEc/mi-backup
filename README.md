# 📺 Lista IPTV M3U — gratis y legal

Lista de **197 canales únicos verificados** (probados con ffprobe: solo los que reproducen video real), organizados en **27 categorías** con orden alfabético.

## 🚀 Cómo usarla

En **Another IPTV** (o cualquier player M3U):

1. Playlist → **+** → URL
2. Pegar: `https://raw.githubusercontent.com/SoyFenixEc/lista-iptv/main/lista.m3u`
3. Cargar y listo ✅
