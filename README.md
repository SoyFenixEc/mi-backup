## Lista organizada: `lista-organizada.m3u`
**197 canales únicos verificados** (probados con ffprobe, solo streams públicos indexados de iptv-org/m3u.cl), ordenados en 27 categorías.
URL: `https://raw.githubusercontent.com/SoyFenixEc/lista-iptv/main/lista-organizada.m3u`

## Categorías individuales (`categorias/*.m3u`)
Cada categoría de la lista organizada tiene su propio archivo.

## Cómo usarla en Another IPTV
Playlist → **+** → URL → pegar → cargar.
